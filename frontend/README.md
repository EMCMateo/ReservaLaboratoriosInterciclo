# Sistema de Gestión de Reservas de Laboratorios

Aplicación web desarrollada con **Angular** (Frontend), **Node.js + Express** (Backend API REST) y **SQLite** (persistencia local).

## Requisitos previos
- Node.js (v18 o superior)
- Angular CLI (`npm install -g @angular/cli`)

## Instalación y ejecución local

### 1. Clonar el repositorio
```bash
git clone [https://github.com/EMCMateo/ReservaLaboratoriosInterciclo.git](https://github.com/EMCMateo/ReservaLaboratoriosInterciclo.git)
cd ReservaLaboratoriosInterciclo
